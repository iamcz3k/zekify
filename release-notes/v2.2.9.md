# Zekify 2.2.9

- Match cards now show the local kickoff date and time alongside the existing countdown or live elapsed timer.
- Added LiveScore using the same ESPN football scoreboard feed currently used by LaCzek Stream.
- Added an optional Android Picture-in-Picture floating player for inline and fullscreen playback, controlled from the app menu and disabled by default.
- Removed developer credits from the in-app menu.
- Changed the Watch Live action to a red button.
- The verified updater opens Android's package installer automatically after download, including after returning from install-permission settings.
- Automatically clear the pending update marker after Android finishes installing the newer version.
